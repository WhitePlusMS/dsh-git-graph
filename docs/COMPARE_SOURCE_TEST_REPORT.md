# 两提交 Diff 与完整历史原文验收

日期：2026-10-10。功能纳入 0.5.0，适配 DSH 0.2.0-rc.2。功能浏览器验收时工作区临时包版本为 0.4.0；发布阶段单独同步版本号与安装说明，并检查类型、构建和安装包。

## 功能与实现范围

1. 选择目标提交，点击“比较提交…”，选择基准提交；变更文件可切换列表 / 树，并点击查看两端统一 Diff。
2. 历史文件查看器可切换“Diff / 完整原文”，选择旧 / 新版本，查看对应 Hash、路径、行号、大小，并复制文本。
3. 重命名使用两端各自的路径；删除默认读取旧版，新增禁用不存在的旧版；根提交、空文件、二进制和超限分别显示。
4. 原文焦点下方向键正常滚动，更改基准立即清除旧文件，切换文件 / 版本后忽略迟到响应。

沿用 Host–Typert–Client、domain DTO / `RemoteResult`、文件树 / 列表与复制按钮。`readFileDiff` 增加可选 `baseHash`，明确比较两端树；`readFile` 仍只接收 Hash 和仓库相对路径。完整原文用只读文本节点渲染并保留换行，没有新增依赖。

## 验证边界

- 原文读取上限为 1 MiB；超限不返回伪装为完整内容的截断文本。二进制不作文本展示。
- 提供统一 Diff 和完整只读文本；本次没有左右 Diff、语法高亮编辑器或当前工作区文件打开能力。
- 复制按钮成功反馈已检查；内置浏览器未读出系统剪贴板，系统剪贴板内容未计作逐字验证通过。原文与换行由 DOM / 真实 Git 测试核对。
- 英文词条覆盖通过类型检查确认；没有另作英文 / 深色浏览器矩阵。
- 本地浏览器验收与安装包检查不代表所有 DSH 版本或生产环境均已验证。
